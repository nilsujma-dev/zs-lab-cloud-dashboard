# Security notes

Switchboard holds cloud credentials and can create and destroy infrastructure.
Read this before changing anything that touches secrets, sessions or the job
runner. The full rule set is the *Security* section of `SPEC.md`; it is not
optional.

## Secrets

Nothing in this repository may contain credentials, API keys, tenant identifiers or
customer data. Local configuration lives in untracked files listed in `.gitignore`.

Where the secrets actually are:

| Secret | Lives | Never |
|---|---|---|
| Operator password, Fernet key | `~/switchboard/.env` on the host (mode 0600), generated by `deploy.sh` | in git, in the image, in `/data` |
| Cloud credentials | `/data/providers.json`, Fernet-encrypted with `SWITCHBOARD_SECRET_KEY` | in clear, in any API response, in a log |
| Zscaler OneAPI secret | `~/.zscaler_api_key` on the host, bind-mounted read-only at `/run/secrets/zscaler_api_key` | copied into `/data` |
| OpenTofu state | S3 bucket `zs-lab-tfstate-<account>` (versioned, SSE-S3, public access blocked) | on local disk |

Before the first push, check the history — not just the working tree:

```sh
git log -p | grep -nE 'AKIA[A-Z0-9]{16}|ASIA[A-Z0-9]{16}|BEGIN (RSA |OPENSSH |EC )?PRIVATE KEY|SWITCHBOARD_(PASSWORD|SECRET_KEY)=[^ ]' || echo clean
```

Look for a secret *value* — a known token format, a private-key block, or an
assignment whose right-hand side is a real literal rather than a placeholder.
A grep for the word `api_key` flags every document that explains where
credentials go and gets ignored, which is worse than not having it.

## Runtime model

- Every route requires the session cookie except `/api/auth/login`, `/api/health`
  and static assets.
- The session cookie is signed, `HttpOnly`, `SameSite=Lax`, 12 h expiry. It is not
  `Secure` in v1 because there is no TLS in front (see the runbook).
- Use-case steps run as an unprivileged user with a minimal environment. The
  provider's decrypted credentials exist only in that subprocess's env for its
  lifetime.
- Job logs are scrubbed before write: stored secret values, `AKIA…`/`ASIA…` key
  ids and 300+ character base64 runs become `<redacted>`.
- The host is reachable only through ZPA. Port 8080 must not be exposed further.

## Lab safety

This project does not touch the OT/IoT lab or any physical equipment. It does
create and destroy cloud infrastructure and ZPA tenant objects: every use-case
switch flip asks for confirmation and shows the exact procedure it will run.
Anything that writes to a shared tenant must snapshot before and verify after, as
the PSE lab does.

## Reporting

Public repository. Report a suspected leak or a vulnerability directly to the
owner rather than in a public issue; rotate first, discuss second (the runbook
covers rotating the password and the key).
